# 超能班周末请假台

把班级群里的周末请假文字整段贴进来，自动认出**谁、什么时候走、哪个宿舍、哪个班组**，整理成一张能勾假条、能导出 Excel 的名单。

- 本机双击就能用，不用装数据库、不用连网、不依赖任何第三方库
- 数据存在自己电脑上（`data/store.json`），随时备份
- 同一个 Wi-Fi 下把网址发给同事，大家同时用；也能设置访问码

![本周名单](shots/desktop-week.png)

---

## 一、一分钟上手

1. **装 Node.js**（只需一次）：打开 <https://nodejs.org/> 下载 LTS 版，一路下一步。
2. **双击 `启动请假台.bat`**，浏览器会自动打开 <http://localhost:8787>。
3. 第一次进入填个称呼（例如「王老师」），之后会记住。
4. 想让别人在外网一起用：**设置 → 开启公网分享**，把 https 地址和 6 位访问码发群里（详见第四节）。

> 用完直接关掉那个黑色窗口就是停止服务；数据在关闭前已经实时写进 `data\store.json`，不会丢。
> 万一双击没反应，先双击 `停止请假台.bat` 清掉旧进程再启动。

## 二、每个周末怎么用

### 1. 粘贴识别（核心）

进入「粘贴识别」，把群里那一大段接龙原样贴进去（一行一个人、带编号也行），点 **识别文案**。

| 你要做的 | 界面怎么配合 |
| --- | --- |
| 看姓名 | 每行是下拉框，名册里的名字直接选；写错字会自动提示「疑似 X」 |
| 看时间 | 每行显示「10月24日 21:30 → 10月25日 20:00」，可手改 |
| 看宿舍/班组 | 输入框可直接改；文案里带了宿舍/班组会优先用文案里的 |
| 名册外的人 | 名字标红，点「补录」一键进名册，以后就认得 |
| 重复的 | 同名且开始时间相同的行标黄，导入时自动跳过 |

确认无误点 **导入 N 条**，直接回到本周名单。

### 2. 本周名单

- 顶部是一条**窄条**（约 48px 高）：左边是周次与左右切周，中间一行小字是截止时间/覆盖班组，右边是 **请假 / 提前 / 周六 / 周日** 四个数字（点一下直接筛）与假条、核对进度；窗口能多显示 3~4 行名单
- 可按 **班组 / 时间 / 宿舍** 排序，可按分类筛选，可搜姓名、宿舍、原因
- 每行最右是一个 **假条 · 核对** 小方块：`✎` 假条已写、`✓` 假条已发、小圆点是核对（虚线=未核对，**黄=有实物**，**蓝=已走**），点一下切换；整行左侧有同色竖条，一眼扫过去就知道进度
- 勾选多行 → 页面底部浮出批量条，一次标「已写 / 已发」、批量核对成「有实物 / 已走」或清除核对，也能批量删除
- 点任意一行打开详情：改时间、改原因、写备注、删除；改动立刻同步给所有在线的人

### 3. 导出

右上角「导出」→

- **Excel（.xlsx）**：一个文件四个工作表 —— `汇总`、`提前请假`、`周六`、`周日`，带表头样式、冻结首行、自动筛选，可直接打印或发家长
- **CSV**：给需要二次处理的人

### 4. 更新名册（宿舍 / 班组 / 班级）

新生来、宿舍换了、分组调整，不用一个个点「编辑」：

1. 打开「学生名册」，最上面一张卡「粘贴名单，自动更新宿舍 / 班组 / 班级」
2. 把名单整段贴进去（一行一个学生，**字段顺序随便**，Excel 里直接复制也行，制表符会自动切开）：

   ```
   刘柏萍 A231 超能一1组 超能1班
   关伊萌 B312 丰泰班2组 丰泰班
   何锦晨 A612 超能二1组 超能2班 13800001111
   ```

3. 点 **识别名单** → 下面出「确认修改」，每行左边是旧值、右边是新值，写 `A533 → B412` 这种；只改你贴了的字段，没写的保持原样
4. 名册里没有的人会标红「名册外」，想收进来就勾上「名册外的姓名一并新增」
5. 点 **应用 N 条**

### 5. 其它视图

| 视图 | 用途 |
| --- | --- |
| 按班组看 | 16 个班组的卡片，每组多少人、谁请假、剩多少人在校 |
| 按宿舍看 | 按宿舍号汇总，方便宿管对床位；没登记宿舍的单独一组 |
| 学生名册 | 243 人；顶部可粘贴名单批量改宿舍/班组/班级，下面可逐个增删改 |
| 设置 | 组织名称、提前请假截止、周日从几点开始算、周次管理、在线成员、备份、操作日志 |

## 三、它能认出什么（识别规则）

时间写法越乱越能体现价值，下面这些都直接认：

```
8月15日21:30           15日21时30分至8月16日20时00分
21点30分                7.17 21:30          8月1 5日（数字中间有空格）
21.30（点号当冒号）      晚上八点 / 下午七点（中文数字 + 时段）
7月18日21:30后（只写开始）  至7月12日22时00分（只写结束）
8月2日中午11.30到晚上8点半  8月15日下课后（保留日期，时间留空待补）
十月二十五日 8:30        二十五号 9点         10/25 8:30        10.25 9:00-16:30
周六 21:30 走、周日 20:00 回来（没写日期也能按本周换算）
```

- **宿舍**：`A231` `B513` `a 231`，以及 `走读`
- **班组**：`超能二3组`、`丰泰班2组`，也认 `超能2班3组`、`超能三 4 组` 这类写法
- **姓名**：名册精确匹配 → 去掉空格再匹配 → 形近字纠错（差一个字给「疑似」）→ 名册外标红
- **姓名只认「请假学生：」**：文案里只要出现 `请假学生：某某`，就以它为准；`我是ＸＸ学生的家长`、`我是ＸＸ妈妈` 这类自我介绍里的名字、以及 `学生家长：ＸＸ` 的家长名（哪怕和某位学生只差一个字）都不会被当成请假学生，一条家长消息只会生成一条记录
- **一句话多人**：一行里出现两个以上名册姓名会按位置拆开；`1.` `2、` 编号、分号、换行也都能拆
- **多段文案一起贴**：一次粘贴好几条家长消息（空行分隔、或每条以「教务老师您好」开头）会**分别**识别成多条，不会把后一条的名字套到前一条上
- **同一个人只出一条**：同一条文案贴了两遍、或两条消息写的是同一个人同一时间，会自动合并成一条（预览里会标「重复」的那条才是库里已有的，不是同一个人出现两次）
- **周几也能认**：没写具体日期时，`周六晚上9点半走，周日8点前回来` 会按当前这一周换算成具体日期；`下周六` 顺延一周
- **中文数字日期**：`十月二十五日`、`二十五号` 直接认；`10/25`、`10.25`、`10月25日` 都行
- **时间靠上下文**：起止时间被「走」「回来」这类词隔开时，会取前两个时间点当起止，并在预览里标「时间待确认」提醒你核对
- **家长整段文案**：家长发来的那种长消息也能整段贴，`我是ＸＸ学生的家长…因为出去玩原因需要请假外出，请假时间…离校期间一切安全问题自行负责` 这种模板会自动去掉客套话和免责声明，只留真实原因；`请假学生：ＸＸ`、`学生家长：ＸＸ`、`家长联系电话：1xx…` 会分别填进姓名、家长姓名、联系电话
- **跨天**：结束时间早于开始时间且没写日期时，自动算到第二天
- **重复判定**：`姓名 + 开始时间` 相同即视为同一条（分类不同也算重复）
- **周次提醒**：文案里的日期不属于当前打开的那一周时，识别结果上方会出现橙色提示条，点一下「切到 X月X日 这一周并导入」即可，分类会按新周重新算

### 分类口径

分类**只看开始时间**，边界由三个时间点决定（默认值）：

| 分类 | 规则（默认） |
| --- | --- |
| 提前请假 | 早于**周六 21:30** |
| 周六 | 周六 21:30 起，到**周日 00:00 之前** |
| 周日 | 周日 00:00 起，到**周日 23:59** |
| 其他 | 更晚 |

**周六 21:30 走的不算提前请假**，算周六——和原表「21.30 前请假」的口径一致。

#### 三个时间点都能改（全局默认）

**设置 → 基础设置**：

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 提前请假截止 | 21:30 | 周六这个时间之前走 = 提前请假；之后 = 周六 |
| 周日从几点开始算 | 00:00 | 周六截止后到第二天这个时间走，仍算周六；之后再算周日 |
| 周日到几点算结束 | 23:59 | 之后（含更晚）算「其他」 |

改完保存，**所有没单独设过的周次**立刻跟着变，已有记录的分类自动重算。

#### 某一周单独设（调休 / 考试周 / 临时提前收假）

本周名单工具栏点 **时间规则** → 三个时间框填好 → **保存到本周**：

- 只影响这一周，其它周次照旧；按钮上会出现一个小圆点，顶部窄条标明「（本周单独设）」
- 保存后这一周已有记录的分类**立刻按新规则重算**
- 想撤销点 **恢复跟随全局**，这一周就回到用全局设置

典型场景：正常周是周日 23:59 结束；调休那周周日 18:00 就要收假，把「周日到几点算结束」改成 18:00 即可——18:00 之后走的会自动落到「其他」，不会被算进周日。

## 四、分享给别人用（外网也能用）

不需要同一个 Wi-Fi，也不用装任何东西：

1. 打开 **设置**，最上面一张卡「远程分享（外网也能用）」
2. 点 **开启公网分享** → 十几秒后出现一个 `https://` 开头的公网地址和一个 **6 位访问码**
3. 两个都复制发到工作群：「打开这个链接，输访问码 515022」
4. 对方在手机或电脑浏览器打开、输入访问码即可；改动实时同步，和你在同一台电脑上操作一样
5. 用完点 **关闭分享**（或者关掉这台电脑）

要点：

- **不用装任何东西**：默认走 Windows 自带的 SSH + serveo 隧道，点一下出地址，不下载、不注册账号
- **第一次打开可能有个英文提示页**：serveo 会先弹一个 `Serveo Browser Warning`，点页面上的 **Continue to Site** 就进去了，之后同一个浏览器不再出现
- **地址是临时的**：关掉分享、重启电脑都会变，变了重新点一次「开启公网分享」就有新地址，数据一条不丢
- **访问码自动加**：公网入口所有请求都要口令（`config.json` 里的 `accessCode`，也可双击 `设置访问码.bat` 改）；本机 `http://localhost:8787` 不需要码
- **电脑别休眠**：休眠了别人打不开，笔记本建议插电
- **第一次打开慢是正常的**：数据要过公共隧道，慢的时候 5–10 秒，页面会显示「正在加载本周数据…」，别急着关。静态文件已开 gzip，比不开快 3–4 倍
- **地址会掉，但能看出来**：服务端每 45 秒自检一次，断了卡片上会变「已断开」并自动重连（最多 3 次）；还不行就点「关闭分享」再「开启公网分享」，会得到一个**新地址**，发新链接即可（老链接作废，页面不会假装还活着）
- 右上角显示当前在线的人；「设置」页有操作日志（谁在什么时候改了什么，保留最近 120 条）
- 自己人都不在了就点「关闭分享」，别一直开着

> 并发说明：两个人同时改同一条时，后保存的会覆盖前一条（不会丢整周数据）。建议一人主录、其他人只勾假条与核对。

### 想换成 Cloudflare 官方隧道

Cloudflare 的免费隧道地址更干净、也不会有提示页，但部分网络（包括本机这条宽带）解析不到 `*.trycloudflare.com`。要用：

1. 装一次：`winget install --id Cloudflare.cloudflared -e`（或把 `cloudflared.exe` 放到项目 `bin\` 目录）
2. 用环境变量指定优先级：`$env:TUNNEL_PROVIDER="cloudflared"`，再启动 `server.mjs`
3. 设置页点「开启公网分享」，地址就是 `https://xxxx.trycloudflare.com`

### 还想更稳 / 更长久的办法

| 方式 | 做法 | 适合 |
| --- | --- | --- |
| 内网穿透（第三方） | 用 cpolar / 花生壳 / frp 把本机 8787 映射成公网地址，把地址发出去 | 想固定域名、长期用 |
| 云服务器（0 元固定地址） | Oracle 永久免费机 + DuckDNS 免费域名，`deploy/install.sh` 一键装完，地址永不变 | 长期用、发一次就完事，见 [`deploy/README.md`](deploy/README.md) |
| 只共享结果 | 每天导出 Excel 发群里 | 零配置，最稳 |

> 数据里含学生姓名、宿舍等敏感信息（身份证号未导入本系统），链接只发给自己人。

| 文件 | 内容 |

- 想整体重来：删掉 `data/store.json` 重启，会自动按 `data/roster.json` 重建

## 六、常见问题

**Q：双击启动闪一下就没了 / 提示 EADDRINUSE**
端口被占用（多半是上次没关干净）。双击 `停止请假台.bat`，再启动；或改 `config.json` 里的 `port`。

**Q：公网地址别人打不开 / 提示需要访问码**
① 先看设置页那个绿点是不是「已开启」，不是就再点一次「开启公网分享」；② 链接和 6 位访问码要一起发，访问码在同一个卡片里；③ 地址是临时的，重启电脑就换了；④ 这台电脑休眠或关机，别人就断了。

**Q：开启公网分享报错「40 秒还没拿到公网地址」**
网络被挡了（学校网络常见）。换个网络、关掉 VPN 再试一次，或者退回用「同一 Wi-Fi + 本机 IP:8787」给同一个办公室的人用。

**Q：识别错了怎么办**
在「粘贴识别」的结果表里当场改；已经导入的点那一行改。姓名下拉框里没有的，先去「学生名册」补人。

**Q：时间写成「下课后」「晚自习后」**
只保留日期，时间列显示待补，导入后在名单里补具体时间即可。

**Q：名册里 58 个人没有宿舍**
是丰泰班的新生（原表 `不要删1` 里就没有宿舍号），导入后会落在「按宿舍看 → 未登记宿舍」。

**Q：原表里有 21 个名字不在名册**
原表就有这些名字（其中 `A612`、`B548` 是把宿舍填进了姓名列的错误数据），所以产品设计成「名册外」提示 + 一键补录，而不是直接丢弃。（这些往期数据只留在 `tools/fixtures/history.json` 做回归测试，不再进网页。）

### 技术要点

- Node.js 20+，**零第三方依赖**；前端原生 ES Module，无框架、无构建步骤
- 端口 8787，监听 `0.0.0.0`（局域网可访问），可用 `PORT` 环境变量或 `config.json` 改
- 存储：单个 JSON 文件 + 40ms 防抖 + 临时文件 `rename`，进程崩溃不写坏
- 核对状态是记录上的一个字段 `check`（空 / `paper` 有实物 / `left` 已走），导出 Excel 时单独一列「核对」
- 同步：前端每 4 秒带 `revision` 拉增量，每 18 秒上报在线状态；正在编辑/输入时会跳过一次刷新，避免打断输入
- 公网分享：`lib/tunnel.mjs` 用 SSH 隧道（`ssh -R 80:127.0.0.1:8887 nokey@localhost.run`）把 **8887** 暴露成 https；8887 只监听本机且强制校验访问码，8787 本机直连免码 —— 隧道流量源地址也是 127.0.0.1，不单独开一个强制口令的端口就区分不出来
- 主要接口：`/api/share`（GET 状态 / POST 开启 / DELETE 关闭）、`/api/bootstrap`、`/api/sync`、`/api/records`（含 `bulk` 批量标假条/核对）、`/api/weeks`、`/api/students`（含 `bulk` 批量改名册）、`/api/presence`、`/api/log`、`/api/export.xlsx`、`/api/export.csv`、`/api/backup`
- 改识别规则只需改 `public/parser.js`，改完跑一遍：
